# HUMAN / AI 移动端 H5 视觉规范

状态：一期实现基准（一屏零滚动版）

## 1. 视觉方向

产品视觉采用“编辑式计时器”方向：黑白为主、单一紫色 AI 状态色、大字号数字、极少容器和装饰。一屏只表达一个主要动作，让玩家把注意力放在关卡和人机速度对比上。

明确不使用：

- 渐变背景、玻璃拟态、霓虹光效。
- 底部导航、悬浮菜单、多层弹窗（**详情 Sheet 除外**）。
- 游戏化金币、徽章、宝箱、连胜火焰。
- 大面积紫色背景或彩色状态面板。
- 为了“丰富”而增加的卡片、阴影和插画。

## 2. Design tokens

### 2.1 颜色

| Token | 色值 | 用途 |
|---|---|---|
| `--color-bg` | `#FFFFFF` | H5 主背景 |
| `--color-text` | `#111111` | 标题、按钮、核心数字 |
| `--color-text-secondary` | `#777777` | 说明、单位、辅助信息 |
| `--color-text-tertiary` | `#999999` | 页脚、弱提示 |
| `--color-surface` | `#F4F4F1` | 棋盘浅底、轻提示块 |
| `--color-border` | `#EEEEEA` | 分割线、禁用边界 |
| `--color-ai` | `#6D5DFC` | AI 呼吸点及唯一强调色 |
| `--color-button-text` | `#FFFFFF` | 黑色主按钮文字 |

胜负状态主要通过符号、标题和字重表达，不新增绿色/红色大色块。紫色只表示 AI 正在处理，不表示胜负。

### 2.2 字体

与前一版相同；数字一律 `tabular-nums`。

### 2.3 间距、圆角与边界

- 主按钮高度：`52px`；圆角 `18px`。
- 页面水平内边距：小屏 `18px`，大于 390px 时 `20px`。

## 3. 全局画布（一屏零滚动）

```css
html.one-screen-app,
html.one-screen-app body {
  height: 100%;
  overflow: hidden;
}

.mobile-shell.one-screen {
  height: 100svh;
  max-height: 100svh;
  overflow: hidden;
}
```

- 目标竖屏：**375×667 ～ 430×932**，含 iOS Safari 安全区。
- **禁止**主流程页面纵向滚动；长内容进入 **详情 Sheet**（Sheet 内部可滚动）。
- 禁止横向滚动。

## 4. 首页

品牌、主张、开始挑战、规则脚注；`landing one-screen` 布局，Hero 在剩余空间垂直居中。

## 5. 游戏页

```text
06 / 20                              ● ● ●
● AI 进行中                    点击不同项

              04.82
               秒
┌──────────────────────────────────────┐
│  [弹幕轨：真实 AI 事件 + 时间戳]      │
│          关卡图 + 点击网格              │
└──────────────────────────────────────┘
              AI 详情 →
```

### 5.1 顶栏

关卡 + 生命；其下 **AI 状态行**（紫点 +「AI 进行中」+ 操作提示）。

### 5.2 倒计时

两位小数 +「秒」；矮屏使用 `timer-compact` 缩小字号。

### 5.3 棋盘

- 宽度 `--play-board-max`：`min(100vw - 内边距, calc(100svh - 固定头尾), 394px)`，保证 **9×9 一屏**。
- 3×3 / 9×9 同规则，完整显示、无横向滚动。

### 5.4 AI 弹幕（游玩）

- 位置：棋盘区域 **上方 overlay**，`pointer-events: none`。
- 内容：**仅基础设施事件**（凭证、Worker、验图、等待、响应耗时等），**提交前不得**出现概率、格子坐标、置信度、heatmap。
- 完整步骤列表在 **「AI 详情」Sheet** 内的 `AI 活动` 面板。
- `prefers-reduced-motion`：弹幕 **静态槽位** 叠放，无横向飘动。

## 6. 单关揭晓

```text
第 06 关                         答案揭晓
[              下一关              ]   ← 主按钮置顶

(✓) 你赢了 · 双轨耗时条
[ 弹幕：事件回放 + Top 概率 + 置信度 + 模型 ms ]
┌──────────────────────────────────────┐
│        缩小热力图 + 短图例            │
└──────────────────────────────────────┘
              AI 详情 →
```

- **「下一关 / 查看结果」** 位于 topline 之下、热力图之上；**仅手动点击**，无自动跳转。
- 耗时对比：**VS race bar**（横向条）为主；Sheet 内保留完整 Insights。
- 揭晓弹幕可含 **Top 候选概率、置信度、模型/全程耗时**（真实数据回放）。
- 完整「AI 决策过程」与活动列表仅在 Sheet。

## 7. 结算页

- `result one-screen`：大数字、核心统计、**Top3 排行 + 本人位**、海报/再玩。
- **完整排行与昵称** 在 Sheet「完整排行与昵称」。

## 8. 分享落地页

与他人成绩 headline + 开始挑战；一屏零滚动。

## 9. 海报弹层

- `poster-shell one-screen`：预览图 `max-height: min(52svh, 420px)`，无页面级滚动。

## 10. 动效与触感

- 页面进入：120–180ms 透明度。
- 揭晓符号：160ms scale。
- AI 弹幕飘动：5.5s 线性；**reduced-motion 关闭飘动**。
- 触感：提交与掉命各一次。

## 11. 响应式与验收

视口：

- `375×667`
- `390×844`
- `430×932`

每路由（首页、倒计时、3×3、9×9、揭晓、结算、分享、海报弹层）必须满足：

- `scrollHeight <= innerHeight`，无横向滚动。
- 揭晓主按钮在 viewport 内且 **高于** 热力图棋盘。
- 游玩提交前 DOM 无 heatmap /「AI 最看好」/「置信度」。
- reduced-motion 下弹幕无 `danmaku-drift` 动画。
- 9×9 格点触控 ≥35px（E2E 断言）。
- 紫色仅出现在 AI 状态点。
