# HUMAN / AI 移动端 H5 视觉规范

状态：一期实现基准

## 1. 视觉方向

产品视觉采用“编辑式计时器”方向：黑白为主、单一紫色 AI 状态色、大字号数字、极少容器和装饰。一屏只表达一个主要动作，让玩家把注意力放在关卡和人机速度对比上。

明确不使用：

- 渐变背景、玻璃拟态、霓虹光效。
- 底部导航、悬浮菜单、多层弹窗。
- 游戏化金币、徽章、宝箱、连胜火焰。
- 大面积紫色背景或彩色状态面板。
- 为了“丰富”而增加的卡片、阴影和插画。

## 2. Design tokens

### 2.1 颜色

| Token | 色值 | 用途 |
|---|---|---|
| `--color-bg` | `#FFFFFF` | H5 主背景 |
| `--color-text` | `#111111` | 标题、按钮、核心数字 |
| `--color-text-secondary` | `#777777` | 说明、单位、辅助信息 |
| `--color-text-tertiary` | `#999999` | 页脚、弱提示 |
| `--color-surface` | `#F4F4F1` | 棋盘浅底、轻提示块 |
| `--color-border` | `#EEEEEA` | 分割线、禁用边界 |
| `--color-ai` | `#6D5DFC` | AI 呼吸点及唯一强调色 |
| `--color-button-text` | `#FFFFFF` | 黑色主按钮文字 |

胜负状态主要通过符号、标题和字重表达，不新增绿色/红色大色块。紫色只表示 AI 正在处理，不表示胜负。

### 2.2 字体

```css
font-family: Inter, -apple-system, BlinkMacSystemFont,
  "SF Pro Display", "PingFang SC", "Noto Sans CJK SC",
  "Helvetica Neue", Arial, sans-serif;
```

| 样式 | 字号/行高 | 字重 | 说明 |
|---|---|---:|---|
| 品牌眉题 | `11px / 1` | 800 | 字距 `0.18em`，全大写 |
| 首页主标题 | `clamp(44px, 13vw, 58px) / 0.96` | 800 | 字距 `-0.055em` |
| 页面标题 | `32px / 1.05` | 800 | 字距 `-0.05em` |
| 倒计时 | `40px / 1` | 600 | 等宽数字，字距 `-0.05em` |
| 结算大数字 | `clamp(104px, 30vw, 132px) / 0.85` | 800 | 字距 `-0.09em` |
| 数据数字 | `22px / 1` | 750 | 等宽数字 |
| 正文 | `14px / 1.55` | 400 | 最长不超过两行 |
| 辅助文字 | `12px / 1.4` | 400–600 | 使用次级灰色 |
| 按钮 | `15px / 1` | 750 | 不使用全大写 |

所有时间、关卡和排名数字启用 `font-variant-numeric: tabular-nums`，避免倒计时跳动时布局抖动。

### 2.3 间距、圆角与边界

- 基础间距序列：`4 / 8 / 12 / 16 / 24 / 32 / 48 / 64px`。
- 页面水平内边距：小屏 `18px`，大于 390px 时 `20px`。
- 主按钮高度：`52px`；圆角 `18px`。
- 浅提示块圆角：`14px`。
- 棋盘视觉单元圆角：3×3 使用 `12px`，9×9 使用 `7px`。
- 分割线：`1px solid var(--color-border)`。
- H5 页面本身不使用阴影；桌面预览时只允许给手机画布添加轻微阴影。

## 3. 全局画布

```css
.mobile-shell {
  width: min(100%, 430px);
  min-height: 100dvh;
  margin: 0 auto;
  padding:
    max(20px, env(safe-area-inset-top))
    18px
    max(18px, env(safe-area-inset-bottom));
  background: #fff;
}
```

- 目标竖屏宽度为 360–430 CSS 像素。
- 桌面浏览器只将内容居中，不添加桌面导航或额外信息栏。
- 页面禁止横向滚动。
- 主内容不得被刘海、圆角屏和底部 Home Indicator 遮挡。
- 按钮与文字不因 320% 文字缩放而相互覆盖；必要时页面允许纵向滚动。

## 4. 首页

布局从上到下固定为品牌、主张、主按钮、规则脚注：

```text
HUMAN / AI


你比 AI
更快吗？
找出唯一不同。
20 关，3 条命。


[              开始挑战              ]
固定 20 关                         全服同题
```

- 品牌位于左上，不使用 Logo 图片。
- Hero 区垂直居中偏下，主标题固定两行。
- 主按钮固定为黑底白字，占满可用宽度。
- 首屏只有一个可点击主操作。
- 按下态使用 `transform: scale(0.985)` 和 `opacity: 0.9`，持续 80ms。

## 5. 游戏页

```text
06 / 20                              ● ● ●

04.82
秒

┌──────────────────────────────────────┐
│                                      │
│          同一张冻结关卡图片           │
│        上方覆盖透明点击网格            │
│                                      │
└──────────────────────────────────────┘

● AI 正在寻找                    点击不同项
```

### 5.1 顶部信息

- 左侧关卡采用 `06 / 20`，13px、800 字重。
- 右侧生命使用三个实心圆；失去的生命显示为空心圆，位置不移动。
- 不显示进度条、设置按钮或退出入口。

### 5.2 倒计时

- 显示两位小数，例如 `04.82`，单位“秒”另起一行。
- 剩余时间低于 1 秒时只提高字重，不改变颜色、不震动整个页面。
- 超时瞬间数字归零并锁定棋盘，避免负数闪现。

### 5.3 棋盘

- 棋盘宽度为 `min(calc(100vw - 36px), 394px)`，保持 1:1。
- 关卡内容是一张预生成的完整 PNG；透明交互网格覆盖其上。
- 3×3 和 9×9 都必须完整显示，不允许横向滚动或局部放大。
- 点击区域覆盖整个单元格，单元格之间不留不可点击缝隙。
- 默认无描边；点击后用 `2px solid #111` 标出选择并立即锁定。
- 图片加载完成前显示固定比例的浅灰占位，不开始倒计时。

### 5.4 AI 状态行

- 顶部分割线后，左侧显示紫色 6px 呼吸点和“AI 正在寻找”。
- 右侧显示唯一操作提示“点击不同项”。
- AI 即使提前完成，也继续显示“正在寻找”，直到玩家提交。
- 呼吸动画周期 1.2 秒；`prefers-reduced-motion` 下保持静态圆点。

## 6. 单关揭晓

```text
第 06 关                         答案揭晓

                 ✓
              你赢了
       双方正确 · 你快了 0.43 秒

你                                  2.48s
AI                                  2.91s

          本局已有 3 关比 AI 更快

[              下一关 · 1              ]
```

- 结果符号为 62px 黑色圆形；内部使用白色 `✓`、`×` 或 `—`。
- 标题只允许“你赢了”“AI 赢了”“AI 掉线”。
- 时间对比使用上下两行，不绘制柱状图或仪表盘。
- “比 AI 更快”仅在双方正确时出现；AI 掉线时不伪装为速度胜利。
- 自动进入下一关前显示明确倒计时；用户可点击按钮提前进入。

揭晓动画：符号以 160ms 淡入并从 `scale(0.94)` 到 `1`；其余内容 100ms 后淡入。禁用动效时直接显示最终状态。

## 7. 结算页

```text
挑战结束                         HUMAN / AI

08
到达关卡

──────────────────────────────────────
比 AI 更快                            3 关
──────────────────────────────────────
本机最佳                            第 10 关
──────────────────────────────────────

[             生成战绩海报             ]
                 再玩一次
```

- 一期无数据库，因此不展示伪造的“全服排名”；第二项改为“本机最佳”。
- 到达关卡使用页面最大字号，是第一视觉焦点。
- 主操作为黑色“生成战绩海报”；“再玩一次”为纯文字次操作。
- 不展示正确率、总耗时、平均速度或综合积分。

## 8. 分享海报

- 尺寸比例固定为 9:16，推荐导出 `1080×1920` PNG。
- 白色背景，无照片、纹理或渐变。
- 顶部为 `HUMAN / AI` 与 `20 关挑战`。
- 中部使用 42–64px 粗体文案：`我有 N 关比 AI 更快`；数字带 3px 下划线。
- 副文案为 `最终到达第 NN 关`。
- 底部为挑战文案、短链接与二维码；二维码周围至少保留四个模块的白边。
- 海报不得展示 OpenAI 标志或暗示 OpenAI 官方背书。

## 9. 组件状态

### 9.1 主按钮

- 默认：黑底白字。
- 按下：轻微缩放与 90% 不透明度。
- 加载：文字替换为动作描述，例如“正在开始”，保留原宽高。
- 禁用：`#E8E8E4` 背景、`#999` 文字，不显示紫色。

### 9.2 网络和错误

- 错误使用页面内联文字，不使用浏览器 `alert`。
- 可恢复错误只提供一个黑色主按钮，例如“重新加载关卡”。
- AI 错误显示“AI 掉线”，玩家的答案与生命结算保持正常。
- 错误文案最多两行，不显示堆栈、状态码或内部请求 ID。

### 9.3 加载

- 首页不显示全屏 Loading。
- 关卡预加载使用与棋盘等大的浅灰占位。
- 超过 800ms 才显示“正在加载关卡”，避免快速闪烁。

## 10. 动效与触感

- 页面进入：120–180ms 透明度变化，不做横向滑屏。
- 按钮反馈：80ms。
- 结果揭晓：160ms。
- AI 呼吸点：1200ms 循环。
- 禁止持续晃动、彩带、粒子和胜利烟花。
- 支持触感的平台，仅在玩家提交和生命减少时各触发一次轻触感；不可连续震动。

## 11. 响应式与验收

必须在以下视口截图验收：首页、3×3 游戏、9×9 游戏、揭晓、结算共五类页面。

- `375×812`
- `390×844`
- `430×932`

每张截图必须满足：

- 无横向滚动和文字截断。
- 9×9 棋盘完整显示，点击网格与图片完全重合。
- 主操作在正常首屏内可达；极小高度设备允许纵向滚动。
- 页面只出现一个视觉主焦点。
- 紫色只出现在 AI 状态点。
- 所有正文与背景对比度至少达到 WCAG AA。
